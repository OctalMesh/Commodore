<h1 align="center">Внесок у Commodore</h1>

Дякуємо за ваш інтерес до **Commodore**.

Commodore є спільним CLI-рушієм і SDK, що використовується в проєктах OctalMesh.
Ми вітаємо внески, особливо виправлення, які покращують надійність,
документацію, досвід розробки та поведінку CLI для різних ролей.

## Перед початком

Будь ласка, відкрийте issue перед початком роботи над великою функцією або
зміною поведінки. Невеликі виправлення багів, оновлення документації та
точкові рефакторинги можна надсилати відразу як pull request-и.

Якщо ви повідомляєте про проблему або пропонуєте зміну, додайте:

- Що ви очікували побачити
- Що сталося фактично
- Кроки для відтворення проблеми
- Відомості про ОС і shell, які мають значення
- Деталі конфігурації `.commodore`, якщо вони впливають на поведінку

## Вимоги до Pull Request

Будь ласка, робіть pull request-и вузькими за змістом і зручними для рев'ю.

- Один pull request має містити одну логічну зміну
- Зберігайте наявну структуру проєкту та правила найменування
- Оновлюйте документацію, якщо змінюється поведінка CLI або публічний SDK
- Додавайте або оновлюйте тести, якщо зміна впливає на поведінку, яку можна
  перевірити автоматично
- Уникайте не пов'язаних із задачею змін форматування

## Нотатки для розробки

Цей репозиторій містить і standalone-бінарник `commodore`, і публічний Go SDK
у `pkg/sdk`.

- Поведінка CLI визначається файлами конфігурації `.commodore`, які знаходяться
  під час виконання
- Ролі foreman, brigadier і worker реалізовані окремо й мають залишатися
  узгодженими між собою
- Зміни семантики команд потрібно оцінювати і для прямого використання CLI, і
  для споживачів SDK
